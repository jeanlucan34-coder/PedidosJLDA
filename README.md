# JLDA Perfumaria — Controle de Pedidos

Sistema simples para controlar os pedidos da JLDA Perfumaria: quem já pagou, quem já recebeu e quem ainda está com entrega pendente.

## Como usar

Abra o `index.html` no navegador (ou acesse pelo GitHub Pages, se ativado neste repositório).

Os dados ficam salvos no navegador de cada dispositivo (localStorage). Use os botões **Exportar backup** / **Importar backup** no rodapé para levar os dados entre o computador e o celular, ou para não perder nada se limpar o navegador.
